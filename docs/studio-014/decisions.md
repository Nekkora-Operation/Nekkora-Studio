## Ressalvas

- O framework não ganhou API nova. Os sites públicos revelaram dois defeitos de identidade, corrigidos num PR próprio
  do framework (D-S014-22). A espera "o texto mudou" (D-S014-17) e o ambiente de produção (D-S014-10) ficam como
  evolução proposta, não implementada.
- A extensão mudou só na captura de nomes (D-S014-21); o laboratório da D-S014-18 continua sem código.
- A integração real com a Anthropic foi **homologada pelo motor** (`RealAnthropicCheck`: a mesma carga minimizada, o
  mesmo Prompt-Mestre v003 e o mesmo `PlanVerifier` do Studio, com projeto sintético). Foram três chamadas reais, cada uma com a chave da usuária lida de `.env` (ignorado no git, nunca impressa) só no ambiente do processo: (1) HTTP 400, chave sem workspace → cabeçalho `anthropic-workspace-id` via `NEKKORA_ANTHROPIC_WORKSPACE_ID`; (2) HTTP 400, `tool_choice` `tool` recusado pelo modelo → `auto` (D-S014-23); (3) **`RESPONSE_VERIFIED`**: 14.462
  tokens de entrada, 676 de saída, cerca de 6,7 s, 2 propostas aceitas e nenhuma recusada. Na interface, o fluxo "Revisar com
  IA" foi provado com o provedor mock. Evidências só com metadados: `evidence/D-chamada-real-anthropic*.json`.
