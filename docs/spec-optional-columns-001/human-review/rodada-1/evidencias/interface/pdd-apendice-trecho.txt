Dados do processo Fluxo: uma transação por linha de uma lista de entrada (CSV ou XLSX); uma planilha Excel de saída, com uma linha por item. A planilha só é gravada se TODOS os itens derem certo (tudo ou nada); nada parcial fica com o nome do arquivo. Entrada: uma coluna por dado de entrada — termo de busca; endereco do artigo. Planilha de saída (aba Dados), colunas nesta ordem: 1. URL ← endereço da página lido (sessão 3, etapa 1) (chave: sem repetição), conferido com a entrada 2. Nome completo ← linha “Nome completo” da tabela (sessão 3, etapa 3); se não existir na página: título da página (sessão 3, etapa 2) 3. Nascimento ← linha “Nascimento” da tabela (sessão 3, etapa 4) Nascimento: data por extenso normalizada para AAAA-MM-DD só se dia, mês e ano estiverem no texto. 4. Morte ← linha “Morte” da tabela (sessão 3, etapa 5); OPCIONAL (o dado não existe em alguns itens): sem o dado, a célula fica vazia Morte: data por extenso normalizada para AAAA-MM-DD só se dia, mês e ano estiverem no texto. 5. Nacionalidade ← linha “Nacionalidade” da tabela (sessão 3, etapa 6) 6. Ocupação ← linha “Ocupação” da tabela (sessão 3, etapa 7); se não existir na página: linha “Campo(s)” da tabela (sessão 3, etapa 8) Itens de uma lista exibida são unidos por ponto e vírgula; o texto é gravado como texto (nunca fórmula). Nada é presumido: dado obrigatório vazio ou data incompleta rejeita o item, e a planilha não é gravada; coluna opcional sem dado fica vazia (nunca recebe outro valor).
